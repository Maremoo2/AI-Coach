# Workout taxonomy 1.1

Workout identity, sport, stimulus and dose are separate fields. v1 expands the
taxonomy beyond the initial feedback prototype so the same evidence pipeline can
represent long endurance, VO2, brick, open-water, mobility and recovery work.

Run types include easy, long, threshold, interval, hills and brick.
Bike types include aerobic, endurance, sweet spot, threshold, VO2 and brick.
Swim types include technique, endurance, CSS and open water.
Strength includes general, full-body, lower and upper. CrossFit remains mixed.

Stimuli are versioned independently and now include aerobic, threshold,
sweetspot, technique, strength, anaerobic, VO2max, long endurance,
strength-endurance, brick, skill, mobility and recovery.

The v1 workout library is deliberately smaller than the taxonomy. The taxonomy
describes what the system can record; the library describes vetted templates the
coach can render. HQ may add templates only through versioned, tested changes.
